## Prerequisites

- Node.js 18+
- Adobe I/O CLI installed globally:
  ```
  npm install -g @adobe/aio-cli
  ```
- Adobe account with access to ACS SANDBOX GDC 01 org

## Step 1 — Clone & Install

```powershell
git clone <your-repo-url>
cd appbuilder-rr-capstone
npm install
```

---

## Step 2 — Login to Adobe I/O

```powershell
aio login
```

Follow the browser prompt to authenticate with your Adobe ID.

---

## Step 3 — Select Org, Project & Workspace

```powershell
aio app use -w Production
```

When prompted about existing `.env`:
- Type `x` to **keep** your existing `.env` (preserves Firefly keys)
- Type `o` to **overwrite** (then re-add Firefly keys manually afterward)

Verify you are in the correct context:
```
1. Org: ACS SANDBOX GDC 01
2. Project: 998VioletGalliform
3. Workspace: Production
```

## Step 5 — Run Locally (Dev Mode)

```powershell
aio app dev
```

- When **"Waiting for the certificate to be accepted..."** appears, open `https://localhost:9080` in the browser and click **Advanced → Proceed**
- App is available at `https://localhost:9080`
- Actions available at:
  - `https://localhost:9080/api/v1/web/appbuilder-rr-capstone/generic`
  - `https://localhost:9080/api/v1/web/appbuilder-rr-capstone/firefly`

Press `Ctrl+C` to stop.

## Step 6 — Deploy to Production


## Common Issues & Fixes

| Issue | Fix |
|-------|-----|
| `HTTP 404` on load | Run `aio app deploy --force-deploy` |
| `Missing FIREFLY_CLIENT_ID` | Re-add Firefly keys to `.env` and redeploy |
| `Unsupported aspect ratio` | Use size `1024x1024` (already fixed) |
| `missing authorization header` | Set `require-adobe-auth: false` in `app.config.yaml` |
| Certificate error in dev | Open `https://localhost:9080` and accept self-signed cert |
| Only 1 action deployed | Always use `--force-deploy` |
